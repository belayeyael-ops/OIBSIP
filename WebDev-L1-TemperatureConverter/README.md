# Web Development & Designing Internship — Temperature Converter

## Project Overview
A responsive temperature converter built as part of the OIBSIP Web Development & Designing Internship.

## Features
- Converts Celsius, Fahrenheit, and Kelvin
- Displays converted values simultaneously
- Input validation
- Error messages for invalid values
- Absolute zero validation
- Responsive and user-friendly interface

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Outcome
This project strengthened my understanding of JavaScript logic, DOM manipulation, input validation, and interactive web development.
