# Web Development & Designing Internship

This repository contains the projects I completed during my Web Development & Designing internship.

## Task 1 – Landing Page

### Objective
To create a clean and responsive landing page using HTML5 and CSS3.

### Steps Performed
- Created a navigation bar with multiple links.
- Designed a hero section with a headline, description, and call-to-action.
- Added multiple content sections.
- Created a footer with contact and social placeholders.
- Used Flexbox and CSS Grid for responsive layout.
- Tested the page on different screen sizes.

### Tools Used
- HTML5
- CSS3
- Flexbox
- CSS Grid

### Outcome
Created a responsive and visually organized landing page that works across different screen sizes.

## Task 3 – Temperature Converter

### Objective
To build an interactive temperature conversion tool using HTML, CSS, and JavaScript.

### Steps Performed
- Created a numeric temperature input.
- Added Celsius, Fahrenheit, and Kelvin unit selection.
- Implemented temperature conversion using JavaScript.
- Added input validation.
- Added an error message for invalid input.
- Added validation for temperatures below absolute zero.
- Displayed the converted temperature in all three units.

### Tools Used
- HTML5
- CSS3
- JavaScript

### Outcome
Created a functional and responsive temperature converter with input validation and support for Celsius, Fahrenheit, and Kelvin.
