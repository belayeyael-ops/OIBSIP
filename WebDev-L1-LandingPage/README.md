
# Web Development & Designing Internship — Landing Page

## Project Overview
A responsive healthcare-themed landing page created as part of the OIBSIP Web Development & Designing Internship.

## Features
- Responsive navigation bar
- Hero section with call-to-action
- Healthcare-focused content sections
- Contact and social media placeholders
- Responsive layout using Flexbox and CSS Grid
- Clean and consistent design

## Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Grid

## Outcome
This project strengthened my understanding of responsive web design, page structure, layout, typography, and user-friendly interfaces.
